# Lowkey Arcade

46 browser games in one page. No downloads, no accounts. Best scores and saves stay in your browser.

**Play:** open `index.html`, or the GitHub Pages link for this repo.

New: Vault Run (stealth heists past robot guards), Trial Burn (2D physics motocross), Breach (hacking puzzles), Drop Zone (battle royale vs 23 android bots), Scrapfist (robot-gang brawler), Void Lancer (space dogfights), Hardpoint (mech combat with a mech workshop), Swarmbreaker (20-minute machine-swarm survival), Span (bridge building) and Rocket Yard (build rockets, reach orbit, land on the moon).

Also: Dead Highway, Long Shot, Night Drift, Deep Hunter, Grave Rounds, Cutline, Iron Bout (2 players on one keyboard), Saltfire, Hive Siege, Fathom Six, Raw Feed, Mega Stomp, Treadfire, Coaster Lab, Blockwild and more.

Built for school Chromebooks: keyboard and trackpad controls, with touch controls too.
3D games use three.js r128 from cdnjs.
