# Lowkey Arcade

26 browser games in one page. No downloads, no accounts. Best scores and saves stay in your browser.

**Play:** open `index.html`, or the GitHub Pages link for this repo.

Highlights: Raw Feed (body-cam shooter, F to shoot), Mega Stomp, Treadfire, Storm Probe, Ore Drift, Deep Cast, Scrap Derby, Canyon Ace, Skyline Run, Reef Resort, Blockwild, Sky Circuit, Coaster Lab and more.

Built for school Chromebooks: keyboard and trackpad controls, with touch controls too.
3D games use three.js r128 from cdnjs.
