# Lowkey Arcade

66 browser games in one page. No downloads, no accounts. Best scores and saves stay in your browser.

**Play:** open `index.html`, or the GitHub Pages link for this repo.

New: Clearance (co-op physics horror for up to 6: haul antiques out of condemned buildings on a cable before something in the dark notices), Switchback (co-op climbing for up to 4: climb an old ropeway's mountain face, wake its stations and ring the summit bell), Mimic (prop hunt for up to 8: become any prop in a closed mall at night while the night crew has three minutes to scan you), Overtime (co-op horror: strip a sealed robot pavilion for parts before sunrise), Lowkey Studio (build your own games with code blocks, pixel art, synth sounds and physics) and Blockwild (dig, build and survive a wild world, now with online co-op for up to 6).

Also: Chassis, Snowline, Dead Signal, Frontline, Implode, Ripsaw, Rail Gunner, Purge Protocol, Night Maw, Junk Karts, Night Rack, Hoop Heat, Knock On, Assembly, Fort Forge, Vault Run, Trial Burn, Breach, Drop Zone, Scrapfist, Void Lancer, Hardpoint, Swarmbreaker, Span, Rocket Yard, Dead Highway, Long Shot, Night Drift, Deep Hunter, Coaster Lab and more.

**Online play:** 33 games can be played with friends on different devices: Clearance, Switchback, Mimic, Overtime, Blockwild, Chassis, Snowline, Dead Signal, Frontline, Implode, Night Rack, Junk Karts, Treadfire, Drop Zone, Iron Bout, Puck Rush, Hoop Heat, Scrap Derby, Night Drift, Comet Tail, Hardlight, Void Lancer, Sky Circuit, Canyon Ace, Putt Planet, Word Rain, Gem Shift, Trial Burn, Beatline, Swarmbreaker, Grave Rounds, Dead Highway and Scrapfist. Jump into a public room, or host a private one and share its 5-character code. It connects browsers directly (PeerJS), so it may not work on networks that block it, such as some school Wi-Fi. Only play with people you know.

Built for school Chromebooks: keyboard and trackpad controls, with touch controls too.
3D games use three.js r128 from cdnjs. Game files ship without indentation to keep the page small; the readable sources live in the project's games folder.
