# Lowkey Arcade

61 browser games in one page. No downloads, no accounts. Best scores and saves stay in your browser.

**Play:** open `index.html`, or the GitHub Pages link for this repo.

New: Chassis (build a fighting robot part by part, then battle in hazard-filled arenas), Snowline (night snowboarding career across four peaks), Dead Signal (co-op survival horror: relight a dead ice-moon station while an alien hunts your light and noise), Frontline (3D real-time strategy with machine armies) and Implode (rig condemned buildings with timed charges and drop them in the zone).

Also: Ripsaw, Rail Gunner, Purge Protocol, Night Maw, Junk Karts, Night Rack, Hoop Heat, Knock On, Assembly, Fort Forge, Vault Run, Trial Burn, Breach, Drop Zone, Scrapfist, Void Lancer, Hardpoint, Swarmbreaker, Span, Rocket Yard, Dead Highway, Long Shot, Night Drift, Deep Hunter, Coaster Lab, Blockwild and more.

**Online play:** 28 games can be played with friends on different devices: Chassis, Snowline, Dead Signal, Frontline, Implode, Night Rack, Junk Karts, Treadfire, Drop Zone, Iron Bout, Puck Rush, Hoop Heat, Scrap Derby, Night Drift, Comet Tail, Hardlight, Void Lancer, Sky Circuit, Canyon Ace, Putt Planet, Word Rain, Gem Shift, Trial Burn, Beatline, Swarmbreaker, Grave Rounds, Dead Highway and Scrapfist. One player hosts a room and shares its 5-character code. It connects browsers directly (PeerJS), so it may not work on networks that block it, such as some school Wi-Fi. Only play with people you know.

Built for school Chromebooks: keyboard and trackpad controls, with touch controls too.
3D games use three.js r128 from cdnjs. Game files ship without indentation to keep the page small; the readable sources live in the project's games folder.
